# 文献背景速查

目标:读者看完报告,能判断这篇论文发在什么水平的期刊、出自什么样的团队、这个团队在这个方向上积累有多深。所有结论都来自可核对的来源,数字必须标出版本和出处。这类信息最怕"看起来很确定但其实是编的",所以宁可写"未能核实",也不要凭记忆补一个数。

## 工作流程

### 1. 先读论文本身

论文首页是作者信息的第一手来源,先从原文拿到:

- 题目、期刊、年份、卷期、DOI。
- 作者署名顺序。
- 通讯作者标记(*、✉、"Corresponding author"、"To whom correspondence should be addressed")。可能有多位通讯作者。
- 共同一作标记(†、"These authors contributed equally")。
- 每位作者的单位(上标对应关系要对准)。通讯作者邮箱照原文抄录。
- 单位和邮箱不一定在作者名下方:不少期刊(尤其是 RSC、较早年份的版式)把它们印在首页底部脚注或页边栏里,作者名下找不到时去这些位置找。

OpenAlex 等数据库的通讯作者标记经常缺失或错误,以论文原文为准。原文标记看不清时,在报告里说明判断依据。

### 2. 运行查询脚本

脚本在本技能目录的 `scripts/lookup.py`,只用 Python 标准库,用完整路径调用:

```bash
python <技能目录>/scripts/lookup.py journal --issn <ISSN>      # 没有 ISSN 时用 --name "<期刊全称>"
python <技能目录>/scripts/lookup.py paper --doi <DOI> --authors 1,2,3,<通讯作者序号>
```

- `journal`:从 LetPub 取 CiteScore(Scopus 学科分区、排名、百分位)、中科院分区表、新锐分区表、预警名单,以及 LetPub 的实时影响因子估算。LetPub 在分区单元格里混入了隐藏的干扰值,直接读网页文字会读错,所以分区数据以脚本输出为准,不要改用网页抓取的文字。
- `paper`:从 OpenAlex 取作者列表、单位,以及指定作者的发文统计、h 指数、研究主题、近 5 年每年发文数和近年论文(先按与本文题目的关键词重合度,再按被引数排序)。`--authors` 填前三位作者和通讯作者在署名中的序号,`-1` 表示末位作者。

脚本失败(网络不通、LetPub 改版)时,改用网页搜索逐项查,并在报告的"数据说明"里写明。

### 3. 补查官方影响因子和 JCR 分区

LetPub 上的官方 IF 和 JCR 分区需要登录,脚本拿不到,用网页搜索补:

- JCR 每年 6 月发布上一年的 IF(例如 2026 年 6 月发布的是 JCR 2025 / IF 2025)。按今天的日期判断最新一版应是哪一年,写明你报告的是哪一版。
- 按下面的顺序找,前一层查不到就往下走,不要在第一层查不到时就放弃:
  1. **官方**:期刊官网或出版社页面(多数会写 "Impact Factor 20XX: x.x",部分会写 JCR 学科排名)、科睿唯安官方发布。
  2. **学术汇总站**:X-MOL(x-mol.com 期刊页)、Peeref(peeref.com/journals)、学术之家(xueshu.com/sci)、LetPub 英文站等。这类站点通常按学科列出 JCR 分区,部分还给排名(如"Q2,83/251");学术之家常给出各学科排名。搜索时可用"<期刊名> JCR 分区 x-mol""<期刊名> peeref journal quartile""<期刊名> 学术之家 JCR"这类关键词。
     - 一个站只有分区、另一个站有排名时,两边合起来用,并分别标来源。
     - 同一页面列了两组没标注的排名时(常见于同时列 JIF 和 JCI 排名),只采用能确认是按 JIF 排的那组,另一组在"数据说明"里提一句。
  3. **其他第三方页面**:只在前两层都没有时使用,并说明是哪个网站。
- JCR 分区按学科分别给出;期刊属于多个学科时逐个列出学科名、分区和排名。可以先用脚本输出的中科院分区小类(就是 WoS 学科)确定要找哪几个学科。
- 标注规则:
  - 官方来源,或两个独立来源数值一致:直接采用。
  - 只有汇总站一个来源,或来源之间不一致:照写,标"二手来源,待核实",不一致时把各来源的数都列出。
  - 汇总站没写年份时,不要自己推断年份,写"版本未注明"。
  - 三层都查不到:写"未能查到,建议用学校账号登录 JCR(jcr.clarivate.com)核对",不要估算。
- LetPub 的"实时影响因子"是按公式估算的非官方数,只能作为补充参考,并标明。

### 4. 查作者

对通讯作者和第一、二、三作者,依次写:

- 姓名(中国学者能查到中文名时附上)、论文发表时的单位(取自原文)。
- 现在的单位和职位/身份(教授、副教授、研究员、博士后、博士生等),来源优先级:单位官网个人主页 > ORCID > Google Scholar / ResearchGate > 新闻报道。
- 研究方向。
- 学术指标:OpenAlex 的总发文、总被引、h 指数(注明来源;不同数据库数值不同,属正常)。

注意:

- **核对身份。** OpenAlex 会把同名作者合并成一个档案。档案的研究主题、单位明显和本文对不上时,写明"档案可能混入同名作者",用 ORCID 或主页核对后再引用其数字。
- **通讯作者同时是一作(或二、三作)时**,在作者部分写"见通讯作者",不重复介绍。
- **作者不足三位**时,如实写明;**共同一作**要标出。
- **学生、早期研究者**公开信息少,查不到就写"公开信息有限",不要猜测身份或去向。
- **论文发表较早**时(例如 5 年以上),作者常已换单位。分别写"发表时"和"现在",不要混为一谈。
- 只写公开的学术职业信息。邮箱只抄论文上印的那个,不去查个人电话、住址、社交账号等私人信息。

### 5. 团队研究方向和近 5 年发文

"团队"默认指通讯作者的课题组。通讯作者不是课题组负责人(例如通讯是博士后,末位作者才是 PI)时,以 PI 为准并说明理由。

- 通讯作者当时不是 PI、现在已独立带组时,在团队部分补一段他/她现在的课题组和方向,因为这往往是这条研究线现在的延续。
- 研究方向:综合课题组主页、OpenAlex 研究主题和近年论文题目,归纳 3–5 个方向,标出与本文直接相关的是哪个。
- 近 5 年发文:列每年发文数(当年未结束要注明"截至查询日")。数据来自 OpenAlex,会包含会议摘要、数据集等,说明这一点即可。
- 代表作:挑 3–5 篇与本文主题最相关、或影响最大的近 5 年论文,写年份、题目、期刊、该负责人的作者位次、被引数。脚本列出的论文只是候选,要看题目判断是否真的相关。
- 一句话判断这个团队在本文方向上的积累(例如"本文是该组钙碳酸盐结晶方向的早期工作,此后持续产出"),判断要有上面的数据支撑。

## 输出前自查

- 每个数字是否都写了来源和版本?有没有凭记忆写的数?
- JCR 和 IF 是否是按今天日期判断的最新一版?找不到时是否如实写明?
- 分区是否取自脚本输出,而不是网页文字?
- 通讯作者是否以论文原文为准?多位通讯、共同一作是否都标出?
- 作者的"发表时单位"和"现单位"是否分开写?
- OpenAlex 档案是否核对过身份?
- 代表作是否真的与本文主题相关?
