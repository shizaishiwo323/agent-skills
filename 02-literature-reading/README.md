# 文献检索与阅读

找到真实可引的文献，并把论文按原文顺序读透。

[返回总览](../README.md)

## researching-academic-literature

**来源类型：** 独立仓库

**用途：** 查找、逐篇核实、筛选和组织真实且高相关的学术文献，用于支撑论文写作。

**何时使用：** 为研究主题、论文章节、实验、模型、理论、综述、方法对比、讨论部分找文献，或加强参考文献列表。

**输入：** 明确的科学问题和文献用途，可附稿件或现有参考文献。

**输出：** 检索主题与关键词、逐条推荐（题目、作者年份期刊、DOI、相关性、适合用于何处）、总结建议和仍缺的文献方向。

**链接：** [researching-academic-literature](https://github.com/shizaishiwo323/researching-academic-literature)

## paper-walkthrough

**来源类型：** 本仓库收录

**用途：** 按原文顺序对论文做章、节、段三级拆解，每段写出“核心内容 → 作用”，完整保留公式、数值、图表编号、引文、假设和局限。

**何时使用：** 论文梳理、逐段精读、整理逻辑骨架、“这篇论文每段在说什么”。只要几句话的摘要时不适用。

**输入：** 论文 PDF 或全文，可含批注。

**输出：** 在对话中直接输出的逐段梳理，结尾附全文逻辑主线。

**链接：** [paper-walkthrough](paper-walkthrough/)
