# 文献检索与阅读

找到真实可引的文献，并把论文按原文顺序读透。

[返回总览](../README.md)

## researching-academic-literature

**来源类型：** 独立仓库

**用途：** 查找、逐篇核实、筛选和组织真实且高相关的学术文献，用于支撑论文写作。

**何时使用：** 为研究主题、论文章节、实验、模型、理论、综述、方法对比、讨论部分找文献，或加强参考文献列表。

**输入：** 明确的科学问题和文献用途，可附稿件或现有参考文献。

**输出：** 检索主题与关键词、逐条推荐（题目、作者年份期刊、DOI、相关性、适合用于何处）、总结建议和仍缺的文献方向。

**链接：** [researching-academic-literature](https://github.com/shizaishiwo323/researching-academic-literature)

## paper-walkthrough

**来源类型：** 本仓库收录

**用途：** 按原文顺序对论文做章、节、段三级拆解，每段写出“核心内容 → 作用”（段落标为“第 n/N 段”），完整保留公式、数值、图表编号、引文、假设和局限；最后附全文骨架，并可按需把全文图表单独梳理。

**何时使用：** 论文梳理、逐段精读、整理逻辑骨架、“这篇论文每段在说什么”。只要几句话的摘要时不适用。

**输入：** 论文 PDF 或全文，可含批注。

**输出：** 在对话中直接输出的逐段梳理，结尾附全文逻辑主线和全文骨架（章节结构 + 每段的概括与作用）。之后询问是否梳理图表；同意则生成一份 Markdown 文档：图片从原文件截取（附 `scripts/extract_figures.py`，支持 PDF 和 Word），表格重建为 Markdown 表格。

**模式：** 默认完整梳理（逐段 + 骨架，结尾询问图表）；说“只梳理骨架”只输出骨架；说“只梳理图表/图片”只输出图表梳理（按论证逻辑排序，讲清现象与作者推测的机理）。图表梳理中首次出现的模型、参数、符号都配术语卡。

**依赖：** 逐段梳理和全文骨架无需额外环境。图表截图需要 Python 3 和 PyMuPDF（`pip install pymupdf`）；智能体在截图前会先检查，缺少时自动安装。

**链接：** [paper-walkthrough](paper-walkthrough/)

## paper-background-check

**来源类型：** 本仓库收录

**用途：** 查一篇论文的“出身”：期刊等级（JCR 分区、Scopus CiteScore 分区与百分位、中科院分区/新锐分区）、影响因子，以及通讯作者、一二三作的单位与身份、团队研究方向和近 5 年发文。

**何时使用：** 上传论文后想先了解期刊几区、影响因子多少、作者是谁、团队做什么方向。

**输入：** 论文 PDF，或 DOI / 题目。

**输出：** 在对话中直接输出的背景报告，每项数据标明来源和版本；查不到或只有二手来源的项会注明“待核实”。

**依赖：** Python 3（只用标准库）。`scripts/lookup.py` 从 LetPub 读期刊分区（自动剔除页面里的隐藏干扰值），从 OpenAlex 读作者与发文数据；官方 IF 和 JCR 分区需联网搜索补查。

**链接：** [paper-background-check](paper-background-check/)
