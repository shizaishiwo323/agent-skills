# 论文逐段逻辑梳理

目标:读完梳理后,读者能知道原文每一段说了什么、按什么顺序说、这一段在全文中起什么作用。这不是摘要。摘要会丢掉段落层级和细节,而用户需要的是按顺序展开的骨架,同时保留完整信息量。所以宁可长,也不要压缩。

## 工作流程

1. **先通读全文再动笔。** 读完摘要、所有章节、结论和附录,确定章节编号、小节划分和每一节的自然段数。先列出这份"段落清单"再写,这样后面的章节不会因为篇幅长而省掉段落层级。
2. **检查 PDF 里的批注**(高亮、彩色下划线、"创新点"等标注)。有的话记下位置,写到对应段落后面。
3. **逐章逐节逐段写。** 按下面的格式要求输出。
4. **输出前自查**(见文末清单)。
5. **直接在对话里输出,不要生成文件。** 这是用户明确要求的。论文很长时,分多条回复接着写,每条结束处注明"接下来梳理第 X 章",用户说"继续"就接着写,不要中途压缩或跳过。

## 范围

- 要梳理:摘要、正文所有章节、结论、附录(附录同样逐段)。
- 不梳理:致谢、参考文献。
- 段落划分以原文版面的自然段为准。排版不清、拿不准时按语义判断,并在该处用"(注:……)"简短说明。

## 结构与标题

1. 层级:章 → 节(小节)→ 段。每一章、每一个小节都拆到"段"这一级。
2. 章、节标题写成"原文编号 + 英文原标题 + 中文译名",例如:`2.2 SIP and EDL polarization 与 EDL 极化`。
3. 标题后用括号标注原文段落数,例如"(共 3 段)"。章标题和第一个小节之间如果有引导段,单独列为"引导段(共 1 段)"。
4. 每段小标题写成"第 n 段:一句话概括本段主题"。

## 每段怎么写

1. 用若干条短要点,按原文句子先后顺序写出这一段的逻辑链。一般原文一两句话对应一条要点。
2. 每条要点写"这句话说了什么 + 它在段内起什么作用"。可用的连接词:起始句/主旨句点明……;以……为例,引出……;按前文顺序分别……;进一步地……;为后文……铺垫;结论句……;与已有工作对比……
3. 每段最后单独一行写"作用:……",说明这一段在全文中的功能,如建立背景、提出问题、点明研究空白、给出依据、设置对照、证明优势、划定边界、展望。
4. 摘要也按段梳理,用编号写逻辑:背景问题 → 方法 → 验证 → 额外发现 → 意义。

写法示范见 `references/examples.md`,动笔前读一遍。示例只用来学习粒度和语气,不要照搬内容。

## 信息量底线(不能丢)

这些内容丢了,梳理就失去了价值,因为读者会回头再去翻原文核对。

1. **保留关键信息**:公式编号(式 n)、图表编号(Fig. n / Table n)、参数值和单位、样品参数、仪器型号、频率范围、噪声水平、反演结果数值、被引文献(作者 + 年份)。
2. **公式**写出核心关系即可(如 T₂ = r/(αρₛ)),不必抄完整推导。推导类段落要写清"从哪一步到哪一步、关键一步是什么"。
3. **假设、适用条件、失效情形、作者自己承认的局限**,单独成条写出,不能被概括掉。
4. **只梳理原文内容,不添加原文没有的观点。** 需要补充时用"(注:……)"标出,与原文内容区分开。

## 文风

- 中文,句子短,一句只说一件事。
- 术语首次出现时附英文或缩写,如 双电层(EDL)。
- 不写成大段文字,也不要过度加粗。

## 开头与结尾

- **开头**:论文中文标题、作者、年份、期刊,再加一行体例说明:"每一章先标段落数,再逐段写'核心内容 → 作用'"。
- **结尾**:"全文逻辑主线(一句话串联)",用 → 把全文从背景、问题、方法、验证、应用到局限和展望串成一条线。
- **批注**:PDF 中有用户批注时,在对应段落后用"📌"注明批注位置和原文对应内容。

## 输出前自查

- 每个章节是否都拆到了段落层级,段落数是否与原文一致?
- 是否保留了原文的数值、公式编号、图号和引文?
- 每段是否都有"作用:"这一行?
- 附录是否也逐段梳理?
- 后半部分的章节,粒度是否和前半部分一致?(最容易出现的问题是越写越粗。)
