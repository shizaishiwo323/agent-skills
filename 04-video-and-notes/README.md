# 视频与笔记

把文档变成讲解视频，把视频和字幕变成笔记。

[返回总览](../README.md)

## doc-to-manim-video

**来源类型：** 独立仓库

**用途：** 把知识文档和模型图做成带旁白的讲解动画视频，用 manimlib、edge-tts 和 HyperFrames 制作，并校验公式按 LaTeX 渲染。

**何时使用：** 公式推导视频、科研教学视频、文档转讲解动画、把概念图或模型图矢量重绘后做动态讲解。

**输入：** Markdown、PDF 或笔记，可附参考图和模型图。

**输出：** 含片头、片尾和旁白的 MP4 视频。

**链接：** [doc-to-manim-video](https://github.com/shizaishiwo323/doc-to-manim-video-skill)

## video-subtitle-notes

**来源类型：** 独立仓库

**用途：** 把视频和字幕转换为中文 Markdown 笔记，保留全部字幕文字，并在合适位置插入从视频截取的画面。

**何时使用：** 手上有视频和 `.srt`、`.vtt`、`.ass`、`.ssa` 字幕，需要课堂笔记、转录笔记或插入截图。

**输入：** 视频文件和字幕文件。

**输出：** 带截图链接的 Markdown 笔记和截图目录。

**链接：** [video-subtitle-notes](https://github.com/shizaishiwo323/video-subtitle-notes)
