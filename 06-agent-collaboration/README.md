## grill-me

**来源类型：** 第三方改版

**用途：** 就计划或设计方案对用户连续追问，沿决策树逐支确认，直到双方理解一致。

**何时使用：** “拷问我”“审一下这个方案”“帮我找方案的漏洞”，或需要压力测试计划和设计时。

**输入：** 一个计划或设计方案。

**输出：** 逐项确认的决策和最终总结。本地改版全程用简体中文，并使用选择题弹窗提问。
